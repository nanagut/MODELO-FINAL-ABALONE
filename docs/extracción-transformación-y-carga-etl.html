3.3 Cambio de nombres, unidades y tipo de variable

data2 <- data %>%
  as.data.frame() %>%
  setNames(c("Sexo", "Largo", "Diametro", "Altura", "Peso",
             "Peso_carne", "Peso_visceras", "Peso_caparazon", "Anillos")) %>%
  mutate(
    id   = row_number(),
    Sexo = factor(Sexo, levels = c("F", "M", "I"),
                  labels = c("Hembra", "Macho", "Infante")),
    across(Largo:Peso_caparazon, ~ .x * 200)
  )

INTERPRETACIÓN: La tabla muestra las primeras seis observaciones de la base de datos transformada. Se observa que la variable Sexo quedó clasificada en tres categorías: Hembra, Macho e Infante. Las variables Largo, Diámetro, Altura y los diferentes pesos fueron multiplicadas por 200 para ajustar su escala. Además, se creó la variable id, que asigna un número consecutivo a cada individuo. Finalmente, la variable Anillos conserva sus valores originales y representa el número de anillos de cada abalone.
